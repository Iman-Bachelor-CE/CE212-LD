This repository contains solutions to the assignments for the CE212: Logic Design course at the Sharif University of Technology, Spring 2021, taught by Dr. Hesabi.

## Notes

In the "Notes" folder, you will find 26 bilingual session notes, one per lecture. I build these from transcripts of the recorded lectures rather than writing them live, so they follow Dr. Hesabi's own sequence and quote the recording where a definition matters. An `_INDEX.md` lists the sessions in order. The lectures are Dr. Hesabi's material; only the note-making is mine.
